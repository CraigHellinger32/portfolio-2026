Carousels

Gallery widget carousel

This is our 'out of the box' carousel functionality, as used in the Jadu gallery widget. Just add the class .js-carousel
<div class="carousel js-carousel">
	<div class="slide">Slide 1 content</div>
	<div class="slide">Slide 2 content</div>
</div>

How carousels work

For our carousels we use Flickity. Documentation for that can be found here. This third party javascript plugin is included in Orbit via it's NPM module. from package.json.

We customise our carousels to mimic the functionality of W3C's working example.. This means disabling Flickity's default accessibility option and creating our own custom functionality. You can find these modifications in js/carousel-init.js in Orbit.

When we style carousels, we always look to ensure that the default style will cover the most use cases. When we need to customise, we do it in this order:

  1. Can it be customised via the provided SASS mixins?flickityDotsPosition and flickityButtonsPosition
  2. If not, can we use Orbit's custom data-attributes?
  3. Otherwise, we need custom CSS and maybe custom javascript too.

Carousel with image links and fade modifier

By default, Flickity uses the transform property to animate slides positioning. You can disable that using the modifier class .carousel--fade

The expected syntax for the FlickityDotsPosition() and FlickityButtonsPosition() SASS mixins can be found in sass/7-Organisms/_carousel.scss. The example above has used the code below to override the default positioning and move the dots to the right and the buttons to the bottom left corner of the carousel container. The available options here should be enough to provide a base for quickly styling the majority of carousel designs. Don't forget, you can always customise this further by writing your own CSS as well.


.style-guide-carousel--example-1 {
    .flickity-page-dots-wrapper {
        @include flickityDotsPosition(right, center, vertical);
    }

    .flickity-buttons-wrapper {
        @include flickityButtonsPosition(left, bottom);
    }
}

Customising using Data attributes

data-carousel-title

Default: Leaving this field empty will default to either the closest h2 or element with the .widget__heading class, or the h1 of the page.

By adding data-carousel-title="My Carousel" to the carousel, now when we navigate using a screenreader, the aria-live dialog will read 'Now viewing slide X of X: My Carousel' and previous and next buttons will read 'Next slide: My Carousel'.


<div class="carousel js-carousel"
    data-carousel-title="My Carousel">
    <div class="slide">Slide 1 content</div>
    <div class="slide">Slide 2 content</div>
</div>

data-carousel-autoplay

Default value: false

Adding data-carousel-autoplay="true" will cause the carousel slides to advance every 3 seconds. The option to pause on hover is enabled by default, but an autoplaying carousel is something we would generally advise against, due to the accessibility and usability issues that poses.

For accessibility reasons, you would also need to create a custom pause button if you decided to enable this feature.

If you want to manually adjust the interval time, you can also specify a time in milliseconds i.e. data-carousel-autoplay="5000" (would increase the wait time to 5 seconds per slide).


<div class="carousel js-carousel"
    data-carousel-autoplay="1000">
    <div class="slide">Slide 1 content</div>
    <div class="slide">Slide 2 content</div>
</div><button class="button">Pause<span class="visually-hidden"> this carousel</span></button>

data-carousel-draggable

Default value: true

Adding data-carousel-draggable="false" will force the user to use the arrow buttons or dots to navigate the carousel. Despite the ability to swipe being a useful feature, particularly on devices, you might decide to do this when the entire slide is also a link to avoid false positives.

data-carousel-dots

This attribute can be used to either remove or reposition the dots on a particular carousel.

Syntax:  data-carousel-dots="$x $y $stack"

Or:  data-carousel-dots="false"

$x value can be either left, center or right. The CSS for that is already available and can be edited in sass/7-Organisms/_carousel.scss

$y value can be either top, center or bottom.

$stack value can be either horizontal, or vertical.

Default value:  center bottom horizontal


<div class="carousel js-carousel"
    data-carousel-dots="false">
    <div class="slide">Slide 1 content</div>
    <div class="slide">Slide 2 content</div>
</div>

<div class="carousel js-carousel"
    data-carousel-dots="top right vertical"
    data-carousel-arrows="false">
    <div class="slide">Slide 1 content</div>
    <div class="slide">Slide 2 content</div>
</div>

data-carousel-arrows

This attribute can be used to either remove or reposition the previous and next arrow buttons on a particular carousel.

Syntax:  data-carousel-arrows="$x $y"

Or:  data-carousel-arrows="false"

$x value can be either left, right or opposite. The CSS for that is already available and can be edited in sass/7-Organisms/_carousel.scss

$y value can be either top, center or bottom.

Default value:  opposite center


<div class="carousel js-carousel"
    data-carousel-arrows="bottom right"
    data-carousel-dots="top left horizontal">
    <div class="slide">Slide 1 content</div>
    <div class="slide">Slide 2 content</div>
</div>

data-carousel-adaptive-height

Default value: false


<div class="carousel js-carousel"
    data-carousel-adaptive-height="true">
    <div class="slide">Slide 1 content</div>
    <div class="slide">Slide 2 content</div>
</div>
